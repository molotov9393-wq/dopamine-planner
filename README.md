# Дофаминовый планер

Небольшое мобильное веб-приложение на русском языке с бумажной текстурой и нежными рукописными акцентами. Данные о задачах, наградах и дневнике хранятся в браузере на устройстве пользователя.

## Запуск локально

Из этой папки запустите любой статический HTTP-сервер. Например, при установленном Node.js:

```sh
npx serve .
```

Откройте показанный адрес на телефоне или используйте адрес компьютера в локальной сети. Для доступа через интернет разместите содержимое папки на статическом хостинге или веб-сервере с поддержкой HTTPS. Приложение не требует сборки или базы данных.

На iPhone откройте сайт в Safari и выберите «Поделиться → На экран Домой». На Android — меню браузера → «Установить приложение».

## Что внутри

- Сегодня: дата, неделя, список дел и прогресс.
- Календарь: выбор дня с отдельным планом задач и записью в дневнике.
- Задачи: выполнение дел и создание своих задач.
- Дневник: заметка дня и отметка настроения.
- Награды: обмен накопленных баллов на маленькие удовольствия.
- Профиль: статистика личных побед и настройки напоминаний о плане на завтра, плане на выбранный день или отдельной задаче. Напоминания в текущей статической версии работают, пока приложение открыто; push при закрытом приложении требует push-сервера и HTTPS.
- Набор из 18 авторских цветных карандашных иллюстраций в формате PNG, включая значки для прогулки, уборки, музыки, перекуса, ухода за растениями и утреннего подъёма.

Состояние хранится локально в `localStorage`; оно не синхронизируется между устройствами.
